# Sample Electrical Schema Dataset

This directory contains sample electrical schema images for testing the
Document Intelligence demo application.

## Files

- `simple_circuit.png` - A simple circuit with resistor and battery
- `parallel_circuit.png` - A parallel circuit with a wiring issue
- `complex_panel.png` - A complex electrical panel layout

These images are generated programmatically for testing purposes.
To regenerate them, run:

```bash
python generate_samples.py
```
